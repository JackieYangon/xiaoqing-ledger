# 小青账本 v1.0.5 · 界面焕新与收支统计

## 更新内容

- 小程序统一青绿色主题，重新整理首页、账单、统计和「我的」页面，精简说明文字。
- 预算使用改为单张卡片，可切换总预算和分类预算，查看已用、剩余、超支金额及使用比例。
- 消费趋势上方新增年度收支组合图：收入与支出使用双折线，结余使用柱状图，负结余显示在零轴下方。
- 月份按顺序展示；没有账单的月份保留标签并断开折线，未来月份隐藏。
- 保留已有账单、预算及备份格式，无需迁移数据。

上述界面与图表更新适用于小程序。Windows 附件为对应版本的桌面安装程序，桌面端保留现有功能与统计界面。

## 下载与使用

| 附件 | 用途 |
| --- | --- |
| `XiaoQing-Ledger-Setup-1.0.5-x64.exe` | Windows x64 安装程序 |
| `Desktop-Quickstart-1.0.5.md` | 中文安装、更新及扫码登录说明 |
| `SHA256SUMS.txt` | 附件 SHA-256 校验值 |

下载 EXE 后按向导安装。已有用户更新前先同步账单并保留必要备份，不要清空应用数据。安装程序未签名，请从本仓库下载并核对校验值。

桌面端需要联网，使用微信扫码并核对两端数字后登录；体验版小程序需要对应访问权限。Source code 附件是源码，不能代替 Windows 安装程序。

GitHub Release 不会自动更新手机上的小程序；小程序上传和微信审核是独立流程。
