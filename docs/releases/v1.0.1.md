# 小青账本 v1.0.1 · Windows 体验版与微信扫码登录

本次发布首次提供可安装的 Windows 电脑端，并新增小程序中的电脑登录确认页。电脑端与小程序使用同一个微信身份，访问同一份个人账本及已加入的群组账本。

> **发布状态：体验测试版（Pre-release）。** 当前电脑端登录码指向小程序体验版，扫码用户需要具备该小程序的体验权限。无法扫码或提示无权限时，请先确认体验成员资格。此版本尚未完成多设备、多账号的完整真实环境验收，不作为稳定正式版发布。

本次在 Windows 11 x64 上验证了安装包对应程序的启动与真实二维码显示。安装程序尚未进行数字签名；请核对仓库来源及 SHA-256，不需要关闭系统安全保护。

## 新增与完善

### 电脑端

- 新增独立 Windows 桌面界面，采用 Electron + Vue，提供侧边导航和适合宽屏的布局。
- 微信扫描小程序码，在手机核对六位数字后确认或取消登录。
- 支持切换个人账本和群组账本，展示账单所属用户的信息。
- 支持收入、支出记录的新增、编辑、删除，月度账单列表与支出分类汇总。
- 支持设置月度总预算；保存时保留已有分类预算。
- 支持分类新增、重命名和删除。历史账单仍保留原分类名称；删除分类会暂停引用该分类的定期任务。
- 支持创建群组、使用邀请码加入群组，以及群主生成邀请码。
- 支持每周、每月定期记账项目的创建、暂停、恢复和删除；手动记账可关联项目，避免同一周期重复记账。

### 微信小程序与云端

- 新增 `pages/desktop-login/index` 电脑登录确认页，支持未登录时先完成微信登录，再返回确认流程。
- 扫码请求两分钟有效，二维码与电脑端凭证分离，同一请求只允许一次确认。
- 手机确认后签发独立电脑会话，最长 24 小时。电脑退出会撤销当前会话，关闭程序后需重新扫码登录。
- 保持原有微信身份对应的账本归属；电脑端不能通过提交其他账号标识读取对方记录。
- 共用现有账本权限、版本冲突检查和幂等写入，网络结果不确定时保留待确认请求，重试避免重复入账。
- 新增独立 `desktop-gateway`；二维码生成设有全局配额：每分钟 30 次、每天 500 次（UTC 时间窗口）。配额不能替代公网网关的按来源限流。
- 微信接口故障仅返回错误阶段与数字代码，避免在响应中泄露密钥或访问令牌。
- 支持 `release`、`trial`、`develop` 登录码模式；当前发布使用 `trial`。

**定期记账仅生成账单，不会发起实际扣款或支付。**

## 安装与登录

1. 下载 `XiaoQing-Ledger-Setup-1.0.1-x64.exe`，按安装向导选择安装目录。
2. 启动小青账本，点击「微信扫码登录」。
3. 用有体验权限的微信账号扫一扫，进入小青账本体验版。
4. 核对手机和电脑上的六位数字一致，确认是本人操作后点击「确认登录」。
5. 登录后选择个人或群组账本，点击「同步」加载最新记录。
6. 使用结束后可点击侧栏底部「退出登录」。

安装包已预配置本项目的公共 HTTPS 服务入口，因此需要联网使用。安装包不包含 AppSecret、云管理员密钥或用户会话凭证。桌面客户端仅在手机确认后获得对应账号的会话。

## 当前边界与注意事项

- 当前登录依赖小程序体验版和体验成员资格，不适用于所有微信用户直接扫码。
- 电脑端尚未提供完整的小程序功能：分类预算编辑、个人资料修改、完整统计视图、账单备份导入导出等仍需在小程序中操作。
- 不支持离线新增账单，未提供自动更新；后续版本需手动下载安装。
- 新用户需有云服务可用且配置正确。网关或微信服务不可用、登录码过期、体验权限缺失时，需恢复服务或刷新登录码后重试。
- 尚未完成真实环境的双设备双向写入、所有群组协作场景和安装/卸载兼容性验收。正式存放重要数据前，请使用小程序导出独立备份。
- JSON 备份不包含群组关系、定期规则与个人资料，备份文件本身未加密。

## 开发者部署

源代码不包含维护者的 AppID、云环境 ID 或服务密钥。自行部署需复制 `.env.example` 为 `.env.local`，填写自己的部署配置，并参照 README 创建数据库、部署两个云函数、配置 HTTPS 网关和限流、小程序体验版及微信服务端密钥。

微信 AppSecret 只配置在云端环境变量 `XQ_WECHAT_APP_SECRET`。不要写入 `.env.local`、前端、安装包或 Git。测试阶段使用 `XQ_MINI_ENV=trial`；发布包含确认页的正式小程序后再切换为 `release`。云端同名变量优先于本地生成配置。
