# 小青账本 v1.0.4 · 本地配置与登录恢复修复

本版修复本地配置和构建目录问题，解决导入仓库根目录时找不到 `app.json`、配置未进入新构建等情况；上传准备会先检查账号所需配置，避免将缺少云环境的预览包用于发布。

> **发布状态：源码体验测试版（Pre-release）。** 此历史版本仅提供源码，不含 v1.0.4 电脑端安装包。带安装包的后续版本使用独立标签 [v1.0.4-r1](https://github.com/JackieYangon/xiaoqing-ledger/releases/tag/v1.0.4-r1)；不能把本版源码压缩包当作安装程序。

## 修复内容

- `dev:mp-weixin` 选择 `dist/dev/mp-weixin/`，`build:mp-weixin` 选择 `dist/build/mp-weixin/`，修复 `miniprogramRoot` 缺失或指向错误目录导致的 `app.json` 报错。
- 普通配置生成、类型检查及其他配置步骤保留已选择的开发或生产目录。
- 未提供替代值时，保留本地项目中已有的 AppID。优先级为进程环境变量、`.env.local`、已有 AppID；显式空 AppID 值仍切换为游客模式。
- 在写入生成文件前解析并校验配置。无效参数、标识及格式损坏的配置文件不会覆盖现有配置；重复执行时不重写内容未变的文件。
- 上传准备（包括 `--prepare-only`）要求同时配置 AppID 和云环境，缺失时提前失败；普通构建仍允许游客预览。
- README 补充云环境缺失与旧编译缓存的登录排查步骤，保留应用存储和用户数据。

## 更新与登录恢复

将自己的 `XQ_APP_ID` 和 `XQ_CLOUD_ENV` 保存在本地、未跟踪的 `.env.local` 或本机进程环境变量中。不要提交实际部署标识，也不要把 AppSecret 放入前端配置。所选云环境中应已部署自己的 `ledger` 云函数。

在仓库根目录执行：

```powershell
pnpm install --frozen-lockfile
pnpm build:mp-weixin
```

等待构建成功，再在开发者工具中重新打开仓库根目录并编译。确认 `project.config.json` 指向 `dist/build/mp-weixin/`，且该目录已有 `app.json`。持续开发时使用 `pnpm dev:mp-weixin`，并保持编译进程运行。

若使用正确配置重新构建后仍出现原来的云环境缺失提示，**仅清理编译缓存**，然后重新编译并登录。保留应用存储和用户数据：清除全部数据可能移除旧账单、待确认请求和登录记录。仅生成配置不会替换已经编译或缓存的代码包。

上传准备前也可显式检查配置：

```powershell
node scripts/prepare-local-config.cjs --mp-mode build --require-cloud
```
