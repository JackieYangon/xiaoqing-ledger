# 小青账本 v1.0.3 · 版本显示与小程序上传修复

本版统一小程序与 Windows 电脑端的版本为 **1.0.3**，修复「我的」版本显示与构建、上传流程脱节的问题。原开发项目读取的旧产物可能仍显示 0.5.0；仅发布安装包和源代码无法更新手机体验包。本版从同一处版本配置生成页面显示、manifest、上传版本与桌面安装包，并在每次小程序上传前强制重新生产构建。

> **发布状态：体验测试版（Pre-release）。** 电脑端扫码登录仍使用小程序体验版，需要体验成员权限。完整多账号、多设备与安装兼容性验收仍需继续完成。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `XiaoQing-Ledger-Setup-1.0.3-x64.exe` | Windows x64 安装程序，支持选择安装目录 |
| `Desktop-Quickstart-1.0.3.md` | 本版安装、登录与更新说明 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |
| GitHub 自动生成的 Source code | 源代码，不是可直接运行的安装包 |

安装程序未进行数字签名，请核对仓库来源与校验值。

1. 下载并运行 `XiaoQing-Ledger-Setup-1.0.3-x64.exe`，按安装向导完成更新。
2. 启动小青账本，点击「微信扫码登录」。
3. 用具备体验权限的微信账号扫码，核对手机与电脑的六位数字一致后，点击「确认登录」。
4. 选择个人或群组账本，点击「同步」加载记录；使用结束后可在侧栏底部退出登录。

安装包预配置本项目公共 HTTPS 服务入口，需要联网使用；不包含 AppSecret、云管理员密钥或用户会话凭证。

## 修复内容

- 以 `package.json.version` 为唯一应用版本来源。「我的」页面直接读取版本，manifest 自动生成版本名称与版本代码，桌面打包继承相同版本。
- 新增小程序上传命令，每次先生产构建与包体检查，再将 `dist/build/mp-weixin` 复制到本次独立上传项目内，避免上传残留的开发产物。
- 上传成功同时检查 CLI 成功状态与本次新回执，防止把退出码为零的错误或旧回执当作上传成功。
- 补充版本生成与上传回归检查，覆盖陈旧配置、同版本重新构建、构建失败阻止上传及回执校验。

明细筛选、预算复用、同进度统计、日历和复制账单继续沿用上一版功能。已有账单、预算与备份格式保持兼容，无需迁移数据。

## 小程序更新

小程序代码上传与 GitHub Release 分别发布。维护者需在小程序管理后台核对上传版本 **1.0.3**，确认相应版本已设为体验版，再重新打开手机体验版，在「我的」检查当前版本。

发布命令与部署配置见 [项目 README](https://github.com/JackieYangon/xiaoqing-ledger/blob/v1.0.3/README.md)。本版不增加云端集合，也不改变既有账单接口。

## 验证情况

- 版本来源、上传流程、账本、云端身份与事务、页面交互、扫码登录回归测试及类型检查通过。
- 小程序生产与开发目录重新构建并通过包体检查，H5 与桌面界面构建通过。
- Windows x64 安装程序构建通过，发布附件附 SHA-256 校验值。

## 使用边界

- 当前是体验测试版，电脑端登录仍受微信体验权限限制；登录码过期时请刷新后重新扫码。
- 不支持离线新增账单，桌面端暂不提供自动更新，需要手动下载安装。
- 个人资料修改与完整 JSON 备份、恢复仍在小程序操作；CSV 用于导出，不能恢复账本。
- 自动测试与构建检查不能替代手机体验版、双设备写入、群组协作及安装兼容性验收。
