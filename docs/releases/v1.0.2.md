# 小青账本 v1.0.2 · 明细筛选、预算复用与收支统计

本次更新完善小程序与 Windows 电脑端的日常记账功能：组合查询账单、沿用上月预算，以及按相同时间进度比较收支。两端使用同一套筛选和统计计算逻辑，并继续访问同一份个人及群组账本。

> **发布状态：体验测试版（Pre-release）。** 当前电脑端登录码仍指向小程序体验版，扫码用户需要具备该小程序的体验权限。本版尚未完成新增界面的真机验收及完整多账号、多设备验收，不作为稳定正式版发布。

## 新增与完善

### 账单查询

- 支持按月、自定义起止日期或全部日期查看账单，可跨月查询。
- 组合使用收入/支出、分类、关键词与金额范围筛选；日期和金额范围包含起止边界。
- 关键词可搜索分类、备注及记账人名称，历史账单中已停用的分类仍可选择。
- 支持按日期或金额升序、降序排列，金额排序保持全部筛选结果的顺序。
- 支持导出当前筛选结果：小程序复制 CSV 文本，电脑端下载 CSV 文件。
- 日历按单月显示，点击日期查看当天明细或补记；切换到跨月或全部日期时使用明细列表。

### 预算计划

- 小程序与电脑端均可编辑月度总预算和分类预算，显示剩余额度及超支提示。
- 可沿用上月总预算及分类限额，历史分类预算一并保留；已有填写内容时，先确认是否替换当前草稿。
- 可将分类预算合计填入总预算；这些快捷操作只修改草稿，点击「保存预算」后才同步。
- 当前月按包含今天的剩余天数计算每日可用额度，未来月份按整月天数计算，过去月份不显示每日可用额度。金额由已保存的预算计算，不代表账户实际余额。
- 同步发现预算已被其他设备或页面更新时，保留当前草稿并阻止旧内容覆盖，需重新加载并核对后再保存。保存前再次检查预算基线，同时保留原有云端版本冲突保护。
- 普通群组成员可查看共享预算，仅群主可修改。

### 收支统计

- 两端提供月度/年度收支、每日/每月趋势、分类排行与前五笔大额记录。
- 当前周期统计截至今天的账单，与上期对应日期比较；短月份或闰日按上期可用日期截断。历史周期按完整周期比较，未来周期暂不统计。
- 新增结余率、日均支出与无支出记录天数。无收入时不计算结余率；日均按统计区间自然日计算，无支出记录不代表实际未消费。
- 点击分类可查看对应日期范围的账单，查询结果与统计口径一致。

### 电脑端操作

- 补齐收支日历、完整分类预算和独立统计页面。
- 支持复制历史账单再记一笔、金额加减计算、常用备注建议以及「保存并再记」。复制时创建新账单，清除原账单标识和定期关联，使用当天日期；原分类已停用时提示重新确认分类。
- 切换账本或退出登录时清理相关编辑状态，避免将上一账本的条件或内容带入另一账本。

## 安装与登录

1. 下载 `XiaoQing-Ledger-Setup-1.0.2-x64.exe`，按安装向导选择安装目录。
2. 启动小青账本，点击「微信扫码登录」。
3. 用具备体验权限的微信账号扫一扫，进入小青账本体验版。
4. 核对手机和电脑上的六位数字一致，确认是本人操作后点击「确认登录」。
5. 登录后选择个人或群组账本，点击「同步」加载最新记录。
6. 使用结束后可点击侧栏底部「退出登录」。

安装包预配置本项目的公共 HTTPS 服务入口，需要联网使用；不包含 AppSecret、云管理员密钥或用户会话凭证。电脑端会话仍须在手机上确认后取得。

## 数据兼容与升级

- 继续使用现有账单格式，本次无需迁移已有账单或预算。
- 旧 JSON 备份仍按原规则校验和合并，相同 ID 不重复导入，当前已有预算不被备份覆盖。
- 预算复制保留历史分类，不重命名旧账单；筛选和统计只读取现有记录，不修改账单。
- 云端写入失败或结果不确定时继续沿用原有待确认请求与幂等机制，恢复同步后再操作。
- 更新电脑端前可使用小程序导出独立 JSON 备份。JSON 不包含群组关系、定期规则和个人资料，备份文件本身未加密。

## 当前边界与注意事项

- 电脑端登录仍依赖小程序体验版及体验成员资格，不适用于所有微信用户直接扫码。
- 个人资料修改、完整 JSON 备份与恢复仍在小程序端操作；CSV 只用于导出，不支持恢复账本。
- 不支持离线新增账单，未提供自动更新，需手动下载安装新版本。
- 发布安装包和源代码不等于更新线上小程序。小程序新功能需编译、上传并部署对应版本后才能使用。
- 网关或微信服务不可用、登录码过期或体验权限缺失时，需恢复服务或刷新登录码后重试。
- 新增界面尚未完成真机验收；完整多账号、双设备双向写入、群组协作及安装/卸载兼容性仍需进一步验收。
- 定期记账只生成账单，不会发起实际扣款或支付。

## 开发者部署

源代码不包含维护者的 AppID、云环境 ID 或服务密钥。自行部署需复制 `.env.example` 为 `.env.local`，填写自己的配置，并按 README 部署云函数、HTTPS 网关及小程序。

微信 AppSecret 仅配置在云端环境变量 `XQ_WECHAT_APP_SECRET`，不要写入前端、安装包或 Git。当前体验发布使用 `XQ_MINI_ENV=trial`；正式小程序发布完成后再切换为 `release`。两端新增功能复用现有账单与预算接口，不增加数据集合，也不要求升级账单格式。
