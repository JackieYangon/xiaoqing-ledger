# 小青账本 v1.0.4-r1 · 登录配置修复与电脑端安装包

本版沿用 v1.0.4 的本地配置、构建目录与登录恢复修复，并以新标签补齐电脑端安装包、使用说明和校验文件。先前的 v1.0.4 仅提供源码，没有电脑端安装附件；两个版本的标签与发布记录分开保留。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `XiaoQing-Ledger-Setup-1.0.4-r1-x64.exe` | Windows x64 安装程序，支持选择安装目录 |
| `Desktop-Quickstart-1.0.4-r1.md` | 本版安装、登录与更新说明 |
| `SHA256SUMS.txt` | 发布附件的 SHA-256 校验值 |
| 自动生成的 Source code | 源代码，不是可直接运行的安装包 |

安装程序为未签名体验测试版，大小为 **120464577 字节**。请核对仓库来源，并使用 `SHA256SUMS.txt` 检查下载文件，不要把源码压缩包当成安装程序。

1. 下载并运行 `XiaoQing-Ledger-Setup-1.0.4-r1-x64.exe`，按安装向导完成更新。
2. 启动小青账本，点击「微信扫码登录」。
3. 使用具备对应小程序访问权限的账号扫码，核对手机与电脑的六位数字一致，再在手机中点击「确认登录」。体验版需要体验成员权限。
4. 选择个人或群组账本，点击「同步」加载记录；使用结束后可在侧栏退出登录。

电脑端需要联网访问对应云服务。打包所用的公共 HTTPS 服务入口与上一已发布安装包一致，已检查入口可达；该检查不包含扫码登录或账单操作。更新前先完成同步并保留必要的 JSON 备份，不要为更新而清空应用数据。

## 保留的修复

- 开发和生产构建分别使用 `dist/dev/mp-weixin/`、`dist/build/mp-weixin/`，并自动设置根项目的 `miniprogramRoot`，解决导入仓库根目录后找不到 `app.json` 的问题。
- 普通配置生成和类型检查保留已选择的构建目录。
- 未提供替代值时保留已有 AppID；优先级为进程环境变量、`.env.local`、已有 AppID。显式空 AppID 仍表示游客模式。
- 在写入前检查参数、标识和配置格式；无效输入不覆盖现有配置，重复执行不重写未变化的内容。
- 上传准备（包括 `--prepare-only`）要求同时配置 AppID 与云环境，缺失时提前失败；普通构建仍支持游客预览。
- 补充云环境缺失和编译缓存的登录恢复指引。账单、预算、备份格式和服务端认证逻辑均保持不变，无需迁移数据。

## 本地构建与登录排查

自行部署时，将自己的 `XQ_APP_ID` 和 `XQ_CLOUD_ENV` 写入未跟踪的 `.env.local` 或本机进程环境变量。不要把实际部署值、AppSecret 或会话凭据写入公开文档、提交或前端代码。所选环境中应已部署 `ledger` 云函数。

```powershell
pnpm install --frozen-lockfile
pnpm build:mp-weixin
```

构建完成后，重新打开开发者工具中的仓库根目录，确认 `project.config.json` 指向 `dist/build/mp-weixin/`，目录内已有 `app.json`，再编译。开发期间可使用 `pnpm dev:mp-weixin` 并保持其运行。

若使用正确配置重新构建后仍出现旧的云环境缺失提示，**仅清理编译缓存**后重试。不要清除应用存储或全部用户数据；其中可能包含旧账单、待确认请求和登录记录。

上传准备前可显式检查配置：

```powershell
node scripts/prepare-local-config.cjs --mp-mode build --require-cloud
```
