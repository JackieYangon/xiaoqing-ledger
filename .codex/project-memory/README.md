# 小青账本项目记忆

本目录仅服务本仓库，随 Git 迁移，不读取、迁入或修改用户全局记忆。

阅读顺序：`status.md` → `decisions.md` → `architecture.md` → `workflows.md`。涉及具体模块时回到源代码和测试核实，记忆不能替代实现。

维护规则：

- 重要变更同步修改对应条目，不重复追加相互矛盾的状态。
- 每条重要结论标注日期、证据和状态：**代码已实现**、**测试通过**、**用户确认**、**尚未验证**。文档历史陈述不能视为本轮验证。
- 仅保存可公开的项目事实和约定；不保存真实部署标识、密钥、会话凭据、账单、个人资料或本机私人绝对路径。配置只记录变量名及仓库相对位置。
- 先核对 Git 状态，保护现有修改；修改后运行适用检查，审查差异和敏感信息，再提交并推送 origin。网络或认证失败保留提交并如实说明，不强制推送。
- 发现背景、旧文档与实现冲突，先在 `status.md` 记录，不凭记忆改产品行为。部署、发布及历史重写需要对应任务授权。
