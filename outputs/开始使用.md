# 小青账本 0.2.0 · 使用说明

工程位置：`D:\Deck\项目\小青账本`

## 启动微信预览

在项目根目录执行并保持终端运行：

```powershell
.\dev.ps1
```

看到 `Build complete` 后，在微信开发者工具打开 `D:\Deck\项目\小青账本`，点击「编译」。根目录配置已指向 `dist/dev/mp-weixin/`。AppID 已配置为 `YOUR_APP_ID`，无需填写 AppSecret。

网页预览：`./dev.ps1 -Target h5`，地址以终端为准。

## 新功能怎么用

1. **快速记账**：首页「记一笔」，选分类，输入 `18.5+6-2` 等加减算式；点击等号查看结果，或直接保存。「保存并再记」保留分类、日期并清空金额和备注。编辑账单时「再记一笔」会复制内容作为新记录。
2. **预算**：首页「预算计划」设置月度总预算和分类限额。每个月独立，留白表示不设限。首页显示剩余额度及分类超支提醒。
3. **日历**：「账单 → 日历」，点击某天查看当天收支，点「补记当天」。再次点击选中日期可回到整月。搜索与分类筛选也会作用于日历。
4. **统计**：切换月度/年度和收入/支出；点击柱形看金额，点击月度分类排名查看对应明细。对比口径是所选周期与上一个完整月份/年度。
5. **分类**：首页「分类管理」或记账页「管理」，添加自己的分类。已有账单或预算使用的分类不能删除。
6. **备份**：「备份恢复 → 复制完整备份」，保存为文本。恢复时粘贴 JSON，点击校验，确认新增/跳过笔数后再合并。重复 ID 保留本机版本，不覆盖已有月份预算和隐私设置。
7. **CSV**：「备份恢复」中选择全部或按月，复制 CSV 数据后保存为 UTF-8 `.csv` 文件即可用 Excel 打开。CSV 不能作为恢复文件。
8. **隐藏金额**：首页点击「隐藏金额」，仅隐藏首页金额，其他页面仍可查看。

## 旧版账单

旧数据保持同一个存储位置，会在首次成功保存时自动升级。损坏数据或写入失败不会被静默覆盖。导入前建议先导出现有备份。

## 当前边界

仍为本地版：尚未接入微信登录、云同步、支付账单自动读取、提醒服务及电脑端。网页、模拟器和手机数据独立，清理存储可能丢失账本，请保留备份。

## 验收清单

- 18.5+6-2 应记录为 22.50；保存并再记后原记录保留，输入金额清空。
- 预算 40、支出 42.50，应显示超支 2.50；其他月份不受影响。
- 自定义分类可用于新增账单，已使用分类不可删除。
- 日历日期正确，支持补记；统计分类可跳转筛选明细。
- 旧备份恢复成功；重复导入不增加记录；同 ID 内容不同不覆盖原账单。
- 首页隐藏金额刷新后保持；JSON 和 CSV 复制内容正确。

H5 浏览器验收不能代替手机微信测试，发布前仍需在开发者工具和手机上确认交互。
