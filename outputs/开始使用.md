# 小青账本 0.5.0 · 使用说明

工程位置：`D:\Deck\项目\小青账本`

## 启动微信预览

在项目根目录执行并保持终端运行：

```powershell
.\dev.ps1
```

看到 `Build complete` 后，在微信开发者工具打开 `D:\Deck\项目\小青账本`，点击「编译」。根目录配置已指向 `dist/dev/mp-weixin/`。AppID 已配置为 `YOUR_APP_ID`，无需填写 AppSecret。

网页预览：`./dev.ps1 -Target h5`，只显示登录提示，业务功能请在微信中验证。

## 先登录

打开小程序点击「微信登录」，成功后进入首页。未登录不能查看账单、统计、预算、备份等功能。记账页的「记账人」显示当前账号标识，不能手工指定其他账号。

「我的 → 退出登录」可隐藏当前账本，不删除云端记录。冷启动或会话过期后需要重新登录；同一个微信账号仍对应原账本。切换用户需在微信中切换实际微信账号后重新打开小程序。

## 新增：头像、群组和定期记账

1. **头像昵称**：「我的」点击顶部头像或昵称 → 选择微信头像、填写微信昵称 → 保存资料。不会静默读取你的微信资料。
2. **群组加入**：「我的 → 群组与账本」创建群组。群主生成邀请后点击「分享给微信好友」，好友打开卡片、登录并确认加入；也可手动填邀请码。邀请有效 7 天，重新生成后旧邀请失效。
3. **切换账本**：「我的」卡片里的「切换账本」选择个人或群组，全部账单、统计和预算随之切换。个人记录不会自动公开到群组。群组成员共享同一份预算；只有群主可设置预算。
4. **记账人**：账单列表显示每笔的记账人头像和昵称；新账单归属当前登录用户。成员只能修改自己的群组账单。
5. **定期记账**：「我的 → 定期记账」输入项目、金额、每周/每月日期、分类并创建。每月 29–31 日遇短月份取月底；按北京时间执行。这里只是自动生成账单，不会发起真实支付。
6. **防重复**：手动记账时选「关联项目」，或在项目上点击「手动记本期」。同一项目同一周期只保留一笔；自动先生成时，手动保存会更新那一笔。未关联项目的普通账单不会被猜测合并。
7. **暂停与删除**：可以暂停项目；恢复后从下一次有效到期日继续，不补记暂停期间。删除已关联账单后，该周期也不会自动重建。
8. **启用后台定时**：开发者工具右键 cloudfunctions/ledger → 上传触发器。控制台应出现 ledgerRecurring，每 5 分钟执行一次。未部署触发器时，只有点击「立即校验到期项目」才会执行该账本的补记。

## 原有功能怎么用

1. **快速记账**：首页「记一笔」，选分类，输入 `18.5+6-2` 等加减算式；点击等号查看结果，或直接保存。「保存并再记」保留分类、日期并清空金额和备注。编辑账单时「再记一笔」会复制内容作为新记录。
2. **预算**：首页「预算计划」设置月度总预算和分类限额。每个月独立，留白表示不设限。首页显示剩余额度及分类超支提醒。
3. **日历**：「账单 → 日历」，点击某天查看当天收支，点「补记当天」。再次点击选中日期可回到整月。搜索与分类筛选也会作用于日历。
4. **统计**：切换月度/年度和收入/支出；点击柱形看金额，点击月度分类排名查看对应明细。对比口径是所选周期与上一个完整月份/年度。
5. **分类**：首页「分类管理」或记账页「管理」，添加自己的分类。已有账单或预算使用的分类不能删除。
6. **备份**：「备份恢复 → 复制完整备份」，保存为文本。恢复时粘贴 JSON，点击校验，确认新增/跳过笔数后再合并。重复 ID 保留当前账本版本，不覆盖已有月份预算和隐私设置。
7. **CSV**：「备份恢复」中选择全部或按月，复制 CSV 数据后保存为 UTF-8 `.csv` 文件即可用 Excel 打开。CSV 不能作为恢复文件。
8. **隐藏金额**：首页点击「隐藏金额」，仅隐藏首页金额，其他页面仍可查看。

## 云同步与旧版账单

1. 微信开发者工具点击「编译」，打开「我的 → 云同步」，确认显示「已同步云端」。环境为 `YOUR_CLOUD_ENV`。
2. 如果旧手机或模拟器存在本地记录，先在此页复制旧本地备份，再点击迁移并确认当前微信账号。原本地数据不会删除。
3. 换手机时使用同一微信账号打开同一小程序，联网后加载云端记录。不同微信账号账本独立。
4. 网络异常时到「云同步」重试。存在待确认操作时先确认其结果，不要清理本地存储。并发冲突需同步后重新确认操作。

云函数 `ledger` 已部署，超时配置为 20 秒。三个集合仅管理员可读写。重新部署步骤见 README。发布前需要实际手机验证新增、编辑、删除及更换设备同步。

## 当前边界

微信端使用云端账本，暂不支持离线记账。H5 网页仅显示登录提示，不能查看本地或云端账本。尚未实现支付账单自动读取、提醒服务及电脑端。云端数据也建议定期导出 JSON 备份。

## 验收清单

- 18.5+6-2 应记录为 22.50；保存并再记后原记录保留，输入金额清空。
- 预算 40、支出 42.50，应显示超支 2.50；其他月份不受影响。
- 所有分类均可修改和删除。历史账单及已有分类预算保留原名称；删除分类会暂停相关定期任务。可删空分类，新增记账前需先添加分类。
- 日历日期正确，支持补记；统计分类可跳转筛选明细。
- 旧备份恢复成功；重复导入不增加记录；同 ID 内容不同不覆盖原账单。
- 首页隐藏金额刷新后保持；JSON 和 CSV 复制内容正确。

H5 浏览器验收不能代替手机微信测试，发布前仍需在开发者工具和手机上确认交互。

## 小程序包体质量检查

执行 `pnpm build:mp-weixin` 会构建正式包，并自动检查三项要求：主包小于 1,500,000 字节、启用组件按需注入、单个图片或音频资源不超过 200,000 字节。检查失败时构建命令返回非零状态。

开发预览包可以执行 `node scripts/check-mp-quality.cjs dist/dev/mp-weixin` 检查。修改 `manifest.json` 后请重启 `dev.ps1`，等待完整编译，再在微信开发者工具点击「编译」并重新运行代码质量检查。脚本统计生成目录的原始文件大小，微信开发者工具最终打包结果以其检查面板为准。
